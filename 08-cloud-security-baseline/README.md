# 08 — Cloud security baseline

## Overview

A secure baseline configuration for a small cloud environment using AWS Free Tier or Azure. Covers IAM, MFA enforcement, logging, storage permissions, least privilege, and backup controls — documented as a reusable checklist and architecture reference.

---

## Objectives

- Design and document a cloud security baseline for a small organisation
- Demonstrate understanding of common cloud misconfigurations
- Produce a reusable security checklist
- Show practical knowledge of IAM and logging controls
