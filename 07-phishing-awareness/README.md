# 07 — Phishing awareness campaign

## Overview

A safe, educational phishing awareness pack designed for a fictional organisation. No real phishing is conducted — the project focuses entirely on staff education materials, reporting culture, and awareness campaign design.

---

## Objectives

- Design a realistic and professional phishing awareness campaign
- Create materials suitable for a non-technical audience
- Demonstrate understanding of human factors in security
- Show ability to communicate security concepts clearly

---

## Skills demonstrated

- Human factors and security awareness
- Communication and campaign design
- Policy support
- Non-technical audience engagement
