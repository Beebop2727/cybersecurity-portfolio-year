# 07 — SIEM detection project

## Overview

A practical SIEM project using Wazuh, Splunk Free, or Elastic. Detection rules are written and tested against simulated suspicious activity in the lab — including failed login bursts, privilege escalation attempts, suspicious PowerShell execution, and new admin account creation.

---

## Objectives

- Deploy and configure a SIEM in the lab environment
- Write detection rules for realistic attack patterns
- Test and validate detections with simulated activity
- Document false positive considerations and tuning decisions

---

## Skills demonstrated

- SOC workflows and tooling
- Log analysis (Windows and Linux)
- Detection engineering
- Alert tuning and false positive management
