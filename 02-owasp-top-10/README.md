# 02 — OWASP Top 10 mini-series

## Overview

A practical demonstration of three to five OWASP Top 10 vulnerabilities using intentionally vulnerable applications such as OWASP Juice Shop or DVWA. Each vulnerability is demonstrated in a controlled lab environment with a clear explanation of the attack, its real-world impact, and how to fix it.

---

## Objectives

- Demonstrate common web application vulnerabilities in a safe lab environment
- Explain each vulnerability clearly for both technical and non-technical audiences
- Document recommended fixes and secure coding practices
- Build familiarity with web application testing methodology
