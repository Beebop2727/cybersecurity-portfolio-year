# Cybersecurity Portfolio Year

A 12-month cybersecurity project portfolio built from scratch, documenting hands-on technical work across infrastructure, offensive security, governance, incident response, and forensics.

Each month produces a GitHub folder with a write-up, diagrams, and professional output — designed to demonstrate practical skills relevant to cybersecurity, infrastructure, and public-sector roles.

> **Related project:** [proxmox-workstation-platform](https://github.com/Beebop2727/proxmox-workstation-platform) — the virtualised workstation and lab environment underpinning most of this work.

## Lab environment

All testing and practical work is carried out in a personal virtualised lab environment — no real organisations, systems, or people are targeted without explicit written permission.

The lab runs on a Proxmox-based workstation platform with isolated VMs. Full documentation is available in the [proxmox-workstation-platform](https://github.com/Beebop2727/proxmox-workstation-platform) repo.

---

## Project structure

Each monthly folder follows the same structure:

```
XX-project-name/
├── README.md          — project overview, objectives, and outcomes
├── report/            — professional written output (report, playbook, policy, etc.)
├── diagrams/          — architecture diagrams, network maps, flowcharts
├── screenshots/       — lab evidence and tool output
└── scripts/           — any automation or tooling written for the project
```

---

## Target positioning

This portfolio is built toward roles in:

- Cybersecurity operations (SOC, IR, detection engineering)
- Infrastructure and systems security
- Governance, risk, and compliance
- Public-sector and government-adjacent cyber roles

---

## Monthly completion checklist

Each project aims to produce:

- [ ] A README explaining the project and why it matters
- [ ] At least one diagram, screenshot, or visual artefact
- [ ] A professional written output (report, playbook, checklist, or case study)
- [ ] A short reflection on lessons learned
- [ ] A LinkedIn post linking to or summarising the project

---

*All work in this repository is conducted ethically and legally within personal lab environments or intentionally vulnerable training platforms.*
