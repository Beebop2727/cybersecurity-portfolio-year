# 11 — Secure coding review

## Overview

A code review of a small intentionally vulnerable Python/Flask or Node.js application. Issues identified include hardcoded secrets, missing input validation, weak authentication, poor error handling, and insecure dependencies — each documented with a before/after fix.

---

## Objectives

- Identify common secure coding issues in a vulnerable application
- Document findings clearly with before and after code examples
- Produce a reusable secure coding checklist
- Demonstrate application security awareness
